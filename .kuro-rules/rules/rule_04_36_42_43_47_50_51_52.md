# RULE 17-BIS: Return Protocol (Learning Recovery)

## Trigger
Return to project after **7+ days of inactivity** OR when you no longer understand your own code.

## Process
1. READ: SESSION_SUMMARY.md last 3 entries
2. IDENTIFY: "What I learned" sections from previous sessions
3. RE-EXPLAIN: Write a 5-sentence summary for your future self explaining:
   - What problem you were solving
   - What you learned that was new
   - What still needs work
   - How to get back up to speed
4. IF you cannot understand: STOP, spend time re-learning before coding

## Template
```
## Return Recovery - [DATE]
**Previous understanding lost**
- Previously understood: [from old "What I learned"]
- What I forgot: [gap analysis]
- Quick relearn plan: [how to recover]
- New understanding captured: [new 5-sentence summary]
```

## Enforcement
IF return to project without reading SESSION_SUMMARY.md learning section: STOP, read first

## Purpose
Prevents: starting from zero every time you return to a project
Ensures: captured learning = reusable knowledge
